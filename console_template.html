Can the Past Predict Tomorrow? (Return Forecasting)

Two very different approaches — a classical statistical model (ARIMA) and a machine learning model (Random Forest) — were tested against each other on identical data, forecasting one day ahead at a time.

When "Safe" Isn't Safe (Value-at-Risk Backtesting)

Three ways of estimating a 1-day, 95%-confidence worst-case-loss threshold were tested against what actually happened, using the standard Kupiec backtest.

Does the Wider World Help? (Macro Enrichment)

India VIX, USD/INR, WTI crude, and the S&P 500 were tested for genuine predictive value beyond each index's own history — not assumed, tested.

How This Works

Honest scope: this is a backtested analytical tool built on historical data, not a live-deployed trading or margining system, and it makes no claim about any specific existing NSE methodology. It is a reproducible input a risk function could use alongside others.
